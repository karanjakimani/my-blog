# My Blog

## Blog Structure
- **/articles**: Directory containing all blog articles.
- **/assets**: Contains images, videos, and other media files used in articles.
- **/css**: Stylesheets for the blog.
- **/js**: JavaScript files for functionalities.

## How to Add Articles
1. Create a new Markdown file in the **/articles** directory.
2. Follow the naming convention: `YYYY-MM-DD-article-title.md`.
3. Start the file with the following YAML front matter:
   ```yaml
   title: "Article Title"
   date: YYYY-MM-DD
   categories: [category1, category2]
   ```
4. Write your article content in Markdown format.
5. Commit and push your changes to the repository.

## Features
- Responsive design for mobile and desktop views.
- Comments section for readers to engage.
- Categorization of articles for better navigation.
